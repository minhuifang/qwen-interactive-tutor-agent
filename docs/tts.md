# 示例课件逐步配音

在“两道示例课件”点击“播放讲解”，按需调用北京地域百炼 `qwen3-tts-flash`，默认音色 `Cherry`。复用服务端 `DASHSCOPE_API_KEY`；可在 `apps/web/.env.local` 设置 `DASHSCOPE_TTS_VOICE` 为官方支持的音色并重启。密钥不会发给浏览器。

讲稿来自当前步骤的 narration（包括 Qwen 改写结果），超过 500 字分段合成。音频 ended 事件推进下一段或下一步骤，画面和代码高亮随步骤变化，不再使用 4.5 秒计时器。暂停保留位置；跳步、切题、切换工作区、改写和恢复讲稿会撤销旧请求与音频事件。重试不会自动发生，错误不阻止手动阅读和跳步。

这是步骤级同步，不是字词时间戳对齐；目前仅覆盖两道示例，新题解法配音尚未接入。客户端停止等待不保证百炼停止计费。按段调用可能产生等待，未预生成全部音频。TTS 按字符计量，不以文本模型 Token 数报告。本地缓存最多 64 段、10 分钟；同段在途请求合并，每进程每小时最多 60 次、最多 2 个不同在途请求。刷新可能复用服务端缓存，重启清除缓存和限额。

接口只接受 localhost 同来源 JSON 请求；无公网鉴权，不部署上线。只允许北京官方音频域名，返回 HTTPS 签名地址，由浏览器直接播放。签名链接短期可访问，不应写入日志或持久文档。

验证：37 项服务端与既有回归测试通过，包含 TTS 缓存、并发合并、输入/来源/配置拒绝、上游故障脱敏和不可信音频地址拒绝；类型检查与构建通过。一段真实讲稿合成成功（未从供应商 usage 读取精确计量）；复用缓存读取音频返回 HTTP 200、audio/x-wav、257324 字节、RIFF 文件头。浏览器出声、暂停恢复和连续播放尚需交互验收，不以接口成功代替听感验收。

接口依据：[百炼 Qwen-TTS 官方文档](https://www.alibabacloud.com/help/en/model-studio/qwen-tts-api)。
